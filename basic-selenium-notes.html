Key Topics Covered in Basic Selenium

WebDriver Architecture

Language bindings, W3C WebDriver Protocol, Browser Drivers (ChromeDriver, GeckoDriver), and Native browser commands.

Environment Setup

Java JDK installation, Eclipse/IntelliJ configuration, Maven project structure, pom.xml dependencies, Selenium 4 updates.

Locators & Strategies

ID, Name, ClassName, TagName, LinkText, PartialLinkText, Absolute/Relative XPath, and CSS Selectors.

WebDriver Methods

Browser navigation, URL fetching, Title verification, Window management (`maximize()`, `fullscreen()`, `close()`, `quit()`).

WebElement Interaction

`sendKeys()`, `click()`, `clear()`, `getText()`, `getAttribute()`, `isDisplayed()`, `isEnabled()`, `isSelected()`.

Best Practices

Clean code conventions, managing driver executables automatically, dynamic locator design, and avoiding hardcoded pauses.
